KKT Server TSPiOT — важно после установки

• Программа работает как HTTP-сервис (по умолчанию порт 2580).
• Закрытие окна (крестик) НЕ завершает процесс — окно уходит в системный трей.
• Восстановить окно: двойной щелчок по иконке в трее.
• Штатное завершение процесса: HTTP POST (или GET)
    http://127.0.0.1:2580/exit
  (порт может быть другим — см. %ProgramData%\CTO_KSM\kktserver\kktserverindy.ini)
• Обновлятор 1C77 KKT Updater и этот установщик останавливают службу через /exit
  (при недоступности HTTP — принудительно).

Автозапуск после входа в Windows включён (ярлык в «Автозагрузка»).
